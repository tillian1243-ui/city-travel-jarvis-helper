# Hotfix v1.0.3

## Причина

GPT Actions не гарантирует перенос скрытого opaque `commit_token` между пользовательскими сообщениями. Даже явное поле в OpenAPI может быть недоступно модели на следующем ходу.

## Решение

- `preview_id` стал основным устойчивым cross-turn идентификатором.
- Preview обязан показывать `Preview ID` в видимом ответе.
- Commit принимает `preview_id` без повторной передачи payload.
- `commit_token` сохранён как дополнительный подписанный механизм.
- Preview остаётся одноразовым, ограниченным TTL и привязанным к capability.
- Дата посещения больше не подставляется как сегодняшняя, если пользователь её не сообщил.
- Конкретный пользовательский комментарий не заменяется выдуманной общей фразой.

## Дополнительная корректность памяти

- HOME_CITY=Москва больше не подставляется в исторические посещения.
- Для нового впечатления нужен реальный город либо однозначно найденное сохранённое место.
- Bistro22 и другие известные петербургские сигналы закреплены за Санкт-Петербургом в Instructions.
